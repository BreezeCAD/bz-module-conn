# BreezCONN — продолжить на устройстве

Модуль [BreezeCAD](https://github.com/BreezeCAD/breezecad): открытая деталь или сборка уходит на телефон или планшет по QR-коду, а изменения потом возвращаются на компьютер. Встал из-за стола — продолжил на iPad — вернул.

## Как пользоваться
1. Откройте и сохраните деталь или сборку. Выберите **Файл → Продолжить на устройстве** (или кнопку **BreezCONN** на ленте «3D-модель»).
2. Наведите камеру телефона или планшета на QR-код. Откроется BreezeCAD на устройстве с этим проектом. Устройство должно быть в той же сети Wi-Fi.
3. Работайте на устройстве. Когда закончите, нажмите там **«Вернуть на компьютер»** и не закрывайте окно на компьютере, пока изменения не придут.
4. Если файл изменился и здесь, и на устройстве, BreezCONN спросит, что оставить: **с устройства**, **своё** или **оба** (файл с устройства ляжет рядом). Заменённые файлы сохраняются в папке настроек BreezeCAD, в `conn/Копии`.

Копия проекта на устройстве после возврата удаляется.

## Почему это модуль
BreezeCAD работает без сети. Передача на устройство — единственное, что слушает сеть, поэтому она вынесена в модуль, который ставят по желанию ([ADR-0011](https://github.com/BreezeCAD/breezecad/blob/next/docs/ADR/0011-breezconn-module.md)). Если Windows спросит про доступ к сети, это спрашивает BreezCONN, который вы поставили сами.

- **Без облака и интернета.** Компьютер никуда не подключается. Он только слушает локальную сеть и только пока открыто окно передачи.
- **Шифрование.** Всё, что идёт по сети, зашифровано ключом из QR-кода (XChaCha20-Poly1305) и привязано к проекту. Чужое устройство без этого QR не получит ничего. Повтор перехваченного запроса не принимается.
- **Документы пишет программа.** Упаковку и возврат файлов делает сама BreezeCAD (команды `conn.pack`, `conn.plan`, `conn.apply`), модуль файлов пользователя не трогает.

## Требования
- BreezeCAD с окнами модулей — `next` после [PR #96](https://github.com/BreezeCAD/breezecad/pull/96). В более старой программе модуль загрузится, но пункта меню не будет (в журнале: «нужна BreezeCAD новее»).
- На устройстве — BreezeCAD для iPad, iPhone или Android: его часть передачи встроена в программу.

## Собрать у себя
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```
Пакет — `build/packages/bz-conn-<версия>-<система>-<архитектура>.bzmod`. Перетащите его в окно BreezeCAD.

Тесты без BreezeCAD: шифрование, QR, сервер против «устройства» (тот же протокол, что на телефоне), и весь круг через окна модуля с подменённой программой.

## Устройство кода
- `src/ConnModule.cpp` — таблица модуля для BreezeCAD (`sdk/bz_module.h`).
- `src/Conn.*` — окна и порядок: упаковать → ждать устройство → принять изменения → применить.
- `src/Net.*` — сервер в локальной сети (перенесён из BreezeCAD `assembly/HandoffNet` без изменений протокола).
- `src/Seal.*` — шифрование и текст QR.
- `third_party/` — Monocypher, qrcodegen, nlohmann/json, doctest ([список и лицензии](third_party/README.md)).

## Выпуск
Поднимите `version` в `module.json`, затем **Releases → Draft a new release**, тег `vX.Y.Z` (та же версия), **Publish release**. GitHub соберёт пакеты под Windows, Linux и macOS и приложит их к выпуску.
